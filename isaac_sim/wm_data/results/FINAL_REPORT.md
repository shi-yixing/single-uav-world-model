# 世界模型的空间记忆：从"能不能读出来"到"有没有用"

**单无人机深度导航（AirDreamer 设定）· 方向一完整报告**　｜　2026-10-17 至 10-21　｜　YIXING

---

## 摘要

AirDreamer 用 DreamerV3 世界模型做无人机深度导航，并认为循环隐状态 h_t 隐式记住了已经离开视野的障碍。我们在同版本仿真器（Isaac Sim 4.1 + OmniDrones）中复现了任务设定，分两部分检验这一说法：

1. **离线：h_t 记住了多少？** 用记忆探针从 h_t 解码机体周围的俯视占据图。h_t 确实保留了视野外障碍的信息（记忆格 AP 0.126，只看当前帧为 0.072，未训练模型为 0.045），但衰减很快：离开视野 1–2 秒后只剩约三分之一。加入"从 h_t 解码占据图"的辅助损失后，可读记忆稳定提升到 0.149（λ=10，3 个种子）和 0.165（λ=30），而深度重建和想象误差不变。
2. **在线：记得更牢能不能飞得更好？** 三轮强化学习对比（原版 DreamerV3 vs 加地图损失 λ=30，各 150 万步）表明：只要训练分布覆盖了相应场景，两组在所有测试场景上都达到 92%–100%，**包括需要记住 6–10 秒的深死胡同和嵌套死胡同**。地图损失没有带来成功率提升，飞行用时反而多 2–3 秒。在训练中没见过的场景上，基线的零样本表现明显更好。

**结论**：在这个任务里，原版 DreamerV3 的记忆对控制已经够用；"可读记忆"的提升没有转化为更好的飞行。决定成败的是训练分布有没有覆盖相应场景，而不是记忆强弱。

## 2. 离线实验：h_t 里有多少记忆

### 2.1 方法
- **数据**：脚本飞手（A* + 纯追踪 + 噪声）在随机场景中飞行，共 1001 条 episode、约 52 万步。每步记录深度、状态、动作、奖励，以及三张以机体为中心的 64×64 俯视图（0.15 m/格）：真实占据、至今见过、当前可见
- **世界模型**：只用深度、状态、动作和奖励离线训练（2 万次更新），从未接触地图标签
- **探针**：冻结世界模型，逐步导出 h_t 和 z_t，训练一个小 MLP 解码 64×64 占据图。按 episode 划分训练 / 早停 / 测试（约 740 / 80 / 88），在没见过的场景上评测
- **指标**：障碍格平均精度（AP，与阈值无关），按三组格子分别计算：当前可见、**记忆**（见过但当前看不到）、从未见过；并按"离开视野多久"分段
- **对照**：未训练的世界模型；只看当前一帧深度的 CNN（无记忆）

### 2.2 结果

记忆格 AP（88 条测试 episode，随机猜测约 0.018）：

| 模型 | 记忆格 AP |
|---|---|
| DreamerV3 世界模型（3 个种子） | 0.126 ± 0.006 |
| + 地图损失 λ=10（3 个种子） | 0.149 ± 0.002 |
| + 地图损失 λ=30（1 个种子） | **0.165** |
| 只看当前帧 | 0.072 |
| 未训练世界模型 | 0.045 |

随离开视野时间的衰减（记忆格 AP）：

| 离开视野 | ≤0.5 s | 0.5–1 s | 1–2 s | 2–4 s | 4–8 s |
|---|---|---|---|---|---|
| 基线 | 0.35 | 0.20 | 0.13 | 0.09 | 0.07 |
| λ = 30 | 0.40 | 0.29 | 0.23 | 0.15 | 0.10 |
| 只看当前帧 | 0.19 | 0.08 | 0.05 | 0.04 | 0.04 |

- h_t 确实有记忆，在 0.5–4 秒内约为"只看当前帧"的 2 倍，但衰减很快
- 地图损失在 1–2 秒处把记忆提升了 74%；4 秒以后各组又趋于接近
- 深度重建误差（约 0.05 m）和想象误差（8 / 16 / 32 步约 0.12 / 0.24 / 0.48 m）在所有模型间没有差异

## 3. 在线实验：记忆增强能否提高飞行成功率

三轮设置相同：DreamerV3 50M，16 架无人机并行，150 万环境步，种子 0，两组分别为原版和加地图损失 λ=30。每轮只改变**训练时出现的场景**，并在同一批固定测试场景上各评测 100 次。

| | 训练场景 | 关键结果 |
|---|---|---|
| 第一轮 | 只有普通随机场景 | 一般场景与 U 形陷阱外起飞约 100%；C 形陷阱内起飞 14% / 9%，都在腔体里撞墙 |
| 第二轮 | + 30% 从 U/C 形陷阱内部起飞 | 两组所有测试 94%–100% |
| 第三轮 | + 30% 从陷阱、深死胡同、嵌套死胡同内部起飞 | 两组所有测试 92%–100%（见下表） |

第三轮评测（各 100 次）：

| 测试场景 | 基线 成功率 / 用时 | + 地图损失 成功率 / 用时 |
|---|---|---|
| 一般场景 | 99% / 8.2 s | 99% / 8.2 s |
| U 形陷阱内起飞 | 100% / 8.9 s | 100% / 10.2 s |
| C 形陷阱内起飞 | 92% / 9.9 s | 97% / 11.4 s |
| 深死胡同（8–10 m） | 98% / 13.6 s | 100% / 16.3 s |
| 嵌套死胡同 | 100% / 12.2 s | 100% / 14.2 s |

**零样本检查**（用第二轮模型直接测死胡同场景，训练时没见过）：

| | 基线 | + 地图损失 |
|---|---|---|
| 深死胡同 | 88% | 21% |
| 嵌套死胡同 | 0% | 2% |

（图：`online_traj.png`、`online_traj_v2.png`、`online_traj_v3.png`、各轮训练曲线）

### 3.1 解读
- **训练分布决定成败**：同一类场景，没训练过时成功率接近 0（C 形陷阱 9–14%，嵌套死胡同 0–2%），训练过之后接近 100%
- **记忆不是瓶颈**：即使是需要记住 6–10 秒前看到的墙的深死胡同，原版 DreamerV3 训练后也能稳定通过。离线探针测到的"记忆衰减快"，并没有限制策略的表现。一种可能的解释是：策略可以用"沿墙飞"这类不依赖长时记忆的行为绕过去；探针测的"可读记忆"也不一定是策略实际使用的那部分信息
- **地图损失没有带来好处**：成功率差异都在统计误差内（100 次评测在 95% 附近约 ±2–3%），而飞行用时稳定多出 1–3 秒。在零样本场景上，加地图损失的模型明显更差（深死胡同 21% vs 88%），可能是辅助损失让世界模型更贴合训练分布，泛化变差（仅一个种子）

## 4. 局限

- 在线实验每组只跑了 1 个随机种子，C 形陷阱 92% vs 97% 这类差距不能下结论
- 训练规模远小于论文（50M 模型、150 万步、单卡 vs 101.7M、2 卡约 39 小时）
- 离线数据来自脚本飞手；探针是一个外加的解码器，只能说明信息"在不在"，不能说明策略"用没用"
- 占据图是 2D 的（障碍都高于飞行高度）；没有动力学域随机化
- 服务器与另一位同学共用，部分训练速度受影响，但不影响结果

## 5. 后续方向

1. **与 JEPA 世界模型对比（进行中，合作）**：已把环境和探针工具包给对方。对方初步发现 LeWM 没有循环状态，几乎不保留记忆，可以作为"无记忆"参照
2. **让记忆真正成为瓶颈**：缩小模型（如 12M）或缩小视场，再比较地图损失的作用
3. **泛化性**：零样本场景是唯一拉开差距的地方，值得用更多种子和更多种未见过的布局系统地测
4. **补种子**：在线每组补 2 个种子，确认用时差异和零样本差异是否稳定
