# 在线 RL 第二轮结果：两组都接近满分，地图损失没有带来成功率提升

日期：2026-10-21｜设置与第一轮相同（DreamerV3 50M，16 架无人机，150 万步，种子 0，λ = 0 / 30），唯一改动：**训练时 30% 的 episode 从 U 形或 C 形陷阱内部起飞**（朝向随机 ±1 rad，终点方位随机 ±60°）

## 一句话结论

**加了陷阱内起飞的训练后，两组都学会了钻出陷阱并绕到终点，所有测试集都在 94%–100%。地图辅助损失没有带来成功率提升，在 C 形陷阱上甚至略低（94% vs 100%）。** 在这个任务里，原版 DreamerV3 的记忆已经够用；离线测到的"记忆增强"没有转化为更好的飞行表现。

## 1. 评测结果（各 100 次，同一批固定场景）

| 测试集 | 基线 | + 地图损失 λ=30 |
|---|---|---|
| 一般场景 | 100% | 100% |
| U 形陷阱外起飞 | 100% | 100% |
| **U 形陷阱内起飞**（面朝后墙） | **100%** | 99%（1 次碰撞） |
| **C 形陷阱内起飞**（面朝后墙） | **100%** | 94%（6 次碰撞） |

到达用时（中位数）：U 形内 7.9 s vs 8.6 s，C 形内 8.2 s vs 9.0 s，基线略快。

C 形陷阱的 100% 对 94%，统计上勉强显著（Fisher 精确检验 p ≈ 0.03），但只有一个种子，不能排除是这次训练的偶然结果。

和第一轮对比：同样的 C 形陷阱测试，第一轮（训练时没有陷阱内起飞）只有 9%–14%，这一轮到了 94%–100%。**决定成败的是训练分布有没有覆盖这类情况，而不是记忆增强。**

## 2. 轨迹（图：online_traj_v2.png）

两组的飞法几乎一样：先在陷阱里原地掉头，从开口或缺口飞出，再贴着陷阱外侧绕到终点。绕行时后墙已经在身后、不在视野里，但两组都没有撞上，说明原版 DreamerV3 的 h_t 已经能记住这段时间（约 2–4 秒）内需要的信息。

## 3. 怎么理解

- 离线实验里，地图损失让"见过但看不到"的障碍更容易从 h_t 里读出来（记忆格 AP 0.126 → 0.165）
- 但在线实验里，基线已经接近满分，没有留给记忆改进的空间（天花板效应）。在这类场景里，绕出陷阱只需要记住 2–4 秒前的东西，而第一步的离线结果显示，基线在这个时间范围内本来就有一定记忆
- 地图损失可能还挤占了一部分世界模型的容量或训练信号，导致 C 形陷阱略差、用时略长；只有一个种子，这一点还不确定

## 4. 下一步可选方向

1. **把现有结果整理成组内汇报（推荐）**：离线部分有清晰的正面结论（h_t 有记忆但衰减快；地图损失能稳定增强可读的记忆、不伤预测），在线部分是一个诚实的负面结论（在当前任务里不转化为成功率提升）。这本身就是完整的故事
2. **设计真正依赖长时记忆的任务**：比如更深的死胡同、迷宫式布局、需要记住 10 秒以上的场景，或者把视场角缩小。然后再比较两组。工作量大约 1–2 天，再加训练时间
3. **配合那位同学的 JEPA 对比**：用同一套探针比较重建式和预测式世界模型的记忆，回答"什么样的世界模型记得更好"
